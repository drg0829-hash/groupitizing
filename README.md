# Groupitizing Experiment

**Version 3.0.0 | Hyperplane-Based Web Numerosity Judgment Experiment**

본 실험은 공간적 그룹핑(Spatial Grouping)의 강도와 색상 그룹핑(Color Grouping)의 일치·불일치가 시각적 개수 판단에 미치는 영향을 조사합니다.

자극은 **초기 무작위 점 배치 → 공간 하이퍼플레인 분할 → 집합별 무게중심 이동 → 조건별 색상 배정** 순서로 생성합니다.

공간 군집화 강도 S는 0~60%를 3% 간격으로 조작하며, 색상 조건은 C1(무채색), C2(공간·색상 일치), C3(직교 불일치)로 구성됩니다.

HTML, JavaScript 및 jsPsych 8.3.0을 사용하며 GitHub Pages에서 실행할 수 있습니다.

## 1. 연구 목적 및 종속변수

화면에 무작위로 생성한 점들을 두 공간 집합으로 분할하고, 각 집합의 무게중심 방향으로 점을 일정 비율만큼 이동시킵니다. 공간 군집화 강도 S와 색상 배정 조건을 조작하여 개수 판단의 변화를 측정합니다.

주요 종속변수는 다음과 같습니다.

- **Accuracy:** 전체 점 개수 판단의 정확도
- **Reaction Time (RT):** 자극 제시부터 Enter 제출까지 걸린 시간
- **Reported Chunks:** 참가자가 입력한 그룹별 숫자의 개수
- **Chunk Sizes:** 참가자가 입력한 각 그룹의 점 개수

Reported Chunks는 지각적 그룹 분할의 간접 지표이며, 실제 인지적 청킹 횟수를 직접 측정한 값은 아닙니다.

## 3. 세 가지 색상 조건

모든 조건은 동일한 공간 자극 생성 알고리즘을 사용합니다. 최초 점 생성, 공간 분할, 무게중심 이동을 수행한 후 조건에 따라 점의 색상을 지정합니다.

| 조건 | 공간 생성 | 색상 배정 |
|---|---|---|
| C1 — 무채색 | 공간 분할 후 S만큼 이동 | 모든 점 회색 |
| C2 — 일치 | 공간 분할 후 S만큼 이동 | 공간 집합별 빨강·청록 배정 |
| C3 — 직교 불일치 | 공간 분할 후 S만큼 이동 | 공간 분할선과 직교하는 색상 분할선으로 배정 |

S=0%에서는 점을 이동시키지 않으므로 초기 무작위 배치 좌표가 그대로 유지됩니다. 단, 최초 배치에서도 점 중심 간 최소거리 40px는 적용됩니다.

C1의 S=0%는 색상 구분과 무게중심 이동이 없는 기준조건입니다.

C2와 C3에서도 S=0%의 공간 좌표 생성 규칙은 같지만 각각의 색상 배정 규칙이 적용됩니다.

## 4. 공통 자극 생성 알고리즘

### 4.1. 초기 무작위 점 배치

1. 전체 점 개수 `n ∈ {8, 9, 10, 11, 12}`를 결정합니다.
2. 논리 캔버스 960×540px에서 각 점의 좌표를 균등 무작위로 추출합니다.
3. 점 중심은 화면 경계에서 최소 27px(여백 20px + 점 반지름 7px) 떨어진 영역에 배치됩니다.
4. 새로 생성한 점과 기존 모든 점의 중심 사이 유클리드 거리를 계산합니다.
5. 거리가 하나라도 40px 미만이면 해당 후보 좌표를 폐기하고 다시 추출합니다.
6. 모든 점의 중심 간 거리가 40px 이상이 될 때까지 반복합니다.

거리 계산식은 다음과 같습니다.

\[
d(P_i,P_j)=\sqrt{(x_i-x_j)^2+(y_i-y_j)^2}
\]

초기 배치 조건은 다음과 같습니다.

\[
d(P_i,P_j)\ge40\text{px}\qquad(i\ne j)
\]

점 좌표는 화면 전체에서 균등하게 추출한 후보 중 거리 조건을 만족하는 좌표를 순차적으로 채택합니다. 따라서 최종 좌표는 점들 사이에 거리 제약이 없는 완전 독립 균등표본과는 다릅니다.

최초 점 생성에서는 40px 조건만 적용하고, 이후 공간 분할이나 무게중심 이동은 아래 규칙에 따릅니다.

### 4.2. 공간 하이퍼플레인 선택

하이퍼플레인은 2차원 화면에서 점들을 두 집합으로 나누는 분할 직선입니다.

점 개수에 따른 목표 공간 분할 A/B를 선택한 후 다음과 같이 분할선을 결정합니다.

1. 전체 방향에서 약 180개의 후보 각도 `θ`를 생성합니다.
2. 각 방향의 단위 법선벡터 `u=(cos θ, sin θ)`를 계산합니다.
3. 모든 점 `Pᵢ=(xᵢ,yᵢ)`을 법선 방향으로 투영합니다.
4. 투영값을 오름차순으로 정렬합니다.
5. 첫 번째 공간 집합의 목표 크기가 `k`일 때, `k`번째와 `k+1`번째 투영값의 간격을 계산합니다.
6. 후보 방향 중 이 간격이 가장 큰 방향을 선택합니다.
7. 두 투영값의 중간을 분할선의 절편으로 설정합니다.

투영값은 다음과 같습니다.

\[
t_i=x_i\cos\theta+y_i\sin\theta
\]

분할선의 방정식은 다음과 같습니다.

\[
u\cdot P=c
\]

투영값이 작은 쪽은 공간 집합 0, 큰 쪽은 공간 집합 1로 지정합니다.

이 방식으로 목표 공간 분할 개수가 정확히 보장됩니다. 분할선의 방향은 매 시행 새로 결정되며 화면의 특정 방향으로 고정되지 않습니다.

가장 큰 투영 간격을 선택하는 규칙은 두 공간 집합을 분리하기 위한 것이며, 모든 시행에서 지각적 그룹핑 강도가 동일하다는 뜻은 아닙니다.

### 4.3. 각 집합의 무게중심 계산

공간 분할이 완료되면 각 집합의 초기 점 좌표를 사용하여 무게중심을 계산합니다.

집합 `g`에 속한 점 개수를 `n_g`라고 할 때 무게중심은 다음과 같습니다.

\[
\mu_g=\frac{1}{n_g}\sum_{i\in g}P_i
\]

각 집합의 무게중심은 해당 집합의 점 좌표 평균입니다.

### 4.4. 무게중심 방향 이동

각 점을 자신이 속한 공간 집합의 무게중심 방향으로 이동시킵니다.

\[
P_i'=(1-S)P_i+S\mu_{\operatorname{group}(i)}
\]

- **S=0%:** 이동하지 않음
- **S=30%:** 무게중심 방향으로 원래 거리의 30% 이동
- **S=60%:** 무게중심 방향으로 원래 거리의 60% 이동

S는 0부터 0.6까지 0.03 간격으로 설정합니다.

이동 후에도 점은 자신이 속한 공간 분할선의 반평면 안에 머무르며 화면의 유효 배치 영역을 벗어나지 않습니다.

### 4.5. 이동 후 점 간 거리

최초 배치에서는 모든 점의 중심 간 최소거리 40px를 보장합니다.

같은 공간 집합에 속한 점들은 동일한 무게중심을 향해 이동하므로 두 점 사이 거리는 다음과 같이 감소합니다.

\[
d_{\text{after}}=(1-S)d_{\text{initial}}
\]

따라서 같은 공간 집합에 속한 점들의 이론적 최소 중심거리는 다음과 같습니다.

| S | 최소 중심거리 |
|---|---:|
| 0% | 40px |
| 15% | 34px |
| 30% | 28px |
| 45% | 22px |
| 60% | 16px |

점의 반지름이 7px이므로 같은 집합 내 점들은 S=60%에서도 겹치지 않습니다.

다만 서로 다른 공간 집합의 점은 각각 다른 무게중심으로 이동합니다. 따라서 두 집합 사이의 점들에 대해서는 동일한 거리 감소 공식이 적용되지 않습니다.

**이동 후에는 전체 점 중심 간 최소거리 제한을 추가로 적용하지 않습니다.** 최종 점 중첩 가능성은 남아 있으며, 실제 최소거리와 중첩된 점 쌍의 수를 계산하여 데이터에 저장합니다.

## 5. 점 개수와 공간 분할 A/B

| 전체 점 개수 | 공간 분할 A | 공간 분할 B |
|---|---|---|
| 8 | 3+5 | 4+4 |
| 9 | 3+6 | 4+5 |
| 10 | 4+6 | 5+5 |
| 11 | 4+7 | 5+6 |
| 12 | 5+7 | 6+6 |

공간 분할 유형 A/B는 점 개수의 조합을 나타내며, 독립적인 반복 실험 조건으로 취급하지 않습니다.

모든 점 개수에서 S=0%일 때 A를 배정하고, S가 3% 증가할 때마다 A와 B를 교대합니다.

- S=0% → A
- S=3% → B
- S=6% → A
- S=9% → B
- …
- S=57% → B
- S=60% → A

따라서 각 점 개수 × 색상 조건의 21회 시행에서 A는 11회, B는 10회 사용합니다.

동일한 `(S, n)` 조합에서는 C1, C2, C3 모두 같은 공간 분할 유형을 사용합니다. 다만 실제 점 좌표와 하이퍼플레인은 각각 독립적인 시행에서 새로 생성합니다.

A/B는 화면의 왼쪽 또는 오른쪽을 의미하지 않습니다. 두 공간 집합의 크기 조합만 나타냅니다.

## 6. 색상 배정 규칙

### 6.1. C1 — 무채색

공간 하이퍼플레인에 따라 두 집합을 분할하고 S만큼 이동시킨 후 모든 점을 회색으로 표시합니다.

RGB는 `(128,128,128)`로 고정합니다.

공간 집합 자체는 내부 계산 및 분석을 위해 유지하지만 참가자에게 집합 경계를 표시하지 않습니다.

### 6.2. C2 — 공간·색상 일치

공간 하이퍼플레인으로 분할한 집합 0과 집합 1을 각각 한 가지 색으로 표시합니다.

- 한 공간 집합: 빨강
- 다른 공간 집합: 청록

같은 공간 집합 안에는 두 색상이 섞이지 않습니다.

색상 배정 방향은 S 단계와 점 개수에 따라 바뀌며, 각 점 개수의 21개 S 단계에서 두 방향이 11:10 또는 10:11로 배정됩니다.

따라서 공간 분할과 색상 분할이 일치합니다.

### 6.3. C3 — 직교 색상 분할

공간 분할을 완료하고 점을 S만큼 이동시킨 후 새로운 색상 분할선을 설정합니다.

색상 분할선은 공간 분할선에 직교합니다.

공간 분할선의 법선벡터가 다음과 같을 때,

\[
u=(u_x,u_y)
\]

색상 분할선의 법선벡터는 다음과 같습니다.

\[
v=(-u_y,u_x)
\]

색상 배정 절차는 다음과 같습니다.

1. 이동이 완료된 점들을 색상 법선벡터 `v` 방향으로 투영합니다.
2. 투영값을 정렬합니다.
3. 목표 빨강·청록 개수에 맞춰 색상 분할선의 절편을 결정합니다.
4. 빨강을 투영값의 작은 쪽 또는 큰 쪽에 배정합니다.
5. 각 공간 집합에 빨강과 청록이 모두 존재하는지 검사합니다.
6. 두 공간 집합 중 하나라도 단색이면 해당 자극을 폐기하고 처음부터 다시 생성합니다.

C3에서 색상 분할선과 공간 분할선은 90° 관계를 유지합니다. 두 직선의 절편은 각자의 계산 규칙에 따라 설정되므로 같은 지점을 지나야 할 필요는 없습니다.

자극 생성은 최대 500회까지 시도합니다. 조건을 만족하는 자극이 생성되지 않으면 오류가 발생합니다.

### 6.4. 공간·색상 분할 개수의 교차

C3에서는 공간 분할과 색상 분할의 목표 점 개수 조합을 반대로 배정합니다.

- 공간 A → 색상 B
- 공간 B → 색상 A

예를 들어 `n=8`일 때 공간 A(3+5)를 사용하면 색상 B(4+4)를 사용합니다.

`n=10`에서 공간 B(5+5)를 사용하면 색상 A(4+6)를 사용합니다.

색상 분할의 방향도 점 개수와 S 단계에 따라 바뀝니다.

이 교차 규칙은 공간 집합과 색상 집합의 목표 개수에 관한 규칙입니다. 실제 색상은 직교 분할선을 이용하여 각 점에 배정합니다.

## 7. 시행 수와 블록 구성

공간 강도 S는 0~60%에서 3% 간격으로 총 21단계입니다.

각 S에서 점 개수 5종과 색상 조건 3종을 한 번씩 시행합니다.

\[
21\times5\times3=315
\]

| 구분 | 시행 수 |
|---|---:|
| C1 — 무채색 | 105회 |
| C2 — 공간·색상 일치 | 105회 |
| C3 — 직교 불일치 | 105회 |
| 점 개수별 합계 | 각 63회 |
| S 단계별 합계 | 각 15회 |
| **본 시행 총합** | **315회** |
| 연습 시행 | 4회 |
| **전체 시행 합계** | **319회** |

### 블록 구성

본 실험은 총 7개 블록으로 구성하며, 각 블록에는 45개 시행을 배정합니다.

S 단계를 세 구간으로 구분합니다.

| 구간 | S 범위 |
|---|---|
| 낮은 S | 0~18% |
| 중간 S | 21~39% |
| 높은 S | 42~60% |

각 블록에는 세 구간에서 S값을 하나씩 배정합니다.

한 S값에 대해 점 개수 5종 × 색상 조건 3종으로 15개 시행이 있으므로 블록당 45회입니다.

각 블록에서는 공간 분할 A 수준이 1~2개, B 수준이 1~2개가 되도록 배정합니다.

7개 블록 전체에서 21개 S값은 각각 정확히 한 번 사용되며 블록 내부 시행 순서는 무작위로 섞습니다.

## 8. 실험 진행 절차

### 8.1. 참가자 정보 입력

실험 시작 시 참가자 이름을 입력합니다.

입력된 정보는 참가자 식별 및 세션 데이터 기록에 사용합니다.

### 8.2. 과제 안내

참가자는 화면에 나타나는 모든 점의 개수를 판단합니다.

점의 색상과 관계없이 전체 점 개수를 세도록 안내합니다. 전체 점 개수는 8~12개 사이입니다.

### 8.3. 연습 시행

연습은 총 4회 실시하며, 본 실험과 동일한 자극 생성 알고리즘을 사용합니다.

연습에서는 응답 후 1초 동안 참가자 응답 및 정답을 제시합니다. 제한시간이 지나면 시간 초과 안내와 정답을 표시합니다.

### 8.4. 본 시행

각 시행은 다음 순서로 진행합니다.

1. 응시점 `+` 표시 — 1,000ms
2. 점 배열 제시 및 응답 — 최대 4,000ms
3. 빈 화면 — 300ms
4. 다음 시행 시작

Enter를 누르면 4초를 기다리지 않고 즉시 해당 시행을 종료합니다.

본 실험에서는 정답 피드백을 제공하지 않습니다.

블록 사이에는 안내 화면이 표시되며 참가자가 스페이스바를 눌러 다음 블록을 시작합니다.

### 8.5. 응답 방법

참가자는 자신이 인식한 그룹별 점 개수를 숫자 키 `1~9`로 차례로 입력합니다.

예를 들어 3개, 4개, 3개로 보였다면 다음과 같이 입력합니다.

`3 → 4 → 3 → Enter`

화면에는 `3 + 4 + 3`처럼 입력한 숫자만 표시합니다. 합계는 화면에 표시하지 않습니다.

- **1~9:** 그룹별 점 개수 입력
- **Backspace:** 마지막 입력 취소
- **Space:** 입력 구분용으로 사용할 수 있으며 숫자 기록에는 영향을 주지 않음
- **Enter:** 입력한 숫자의 합계를 제출하고 즉시 종료

제한시간인 4초가 지나면 제출되지 않은 응답은 시간 초과로 처리합니다.

시간 초과 시 입력된 숫자들은 부분 응답으로 별도 기록하며, 정식 응답 및 RT는 결측으로 처리합니다.

## 9. 화면 크기 및 표시 방식

자극은 960×540px의 논리 좌표계에서 생성합니다.

CSS를 이용하여 브라우저 화면 크기에 맞춰 비례 축소할 수 있으며 논리 좌표와 화면 비율은 유지됩니다.

점의 반지름은 논리 좌표 기준 7px입니다.

초기 점 중심의 허용 범위는 다음과 같습니다.

- X축: 27~933px
- Y축: 27~513px

점의 중심 간 최소거리 40px는 화면에 그려지는 크기가 아니라 논리 좌표를 기준으로 계산합니다.

공간 분할선, 색상 분할선, 투영축, 무게중심은 참가자 화면에 표시되지 않습니다.

## 10. 데이터 저장 항목

jsPsych를 이용하여 시행별 응답 및 자극 정보를 수집합니다.

실험 종료 시 Google Apps Script 웹 앱으로 JSON 데이터를 전송합니다.

전송 데이터는 시행별 데이터(`trial_rows`), 점별 좌표 데이터(`dot_rows`), 세션 데이터(`session_rows`)로 구성됩니다.

### 10.1. 시행별 데이터

**기본 정보**

- `phase`, `block`, `trial_in_block`, `main_trial_number`
- `condition`, `n`, `total_dots`
- `spatial_condition`, `color_condition`

**공간 군집화 강도와 분할**

- `s_index`, `s_percent`, `s`
- `spatial_partition_id`, `spatial_partition`
- `color_partition_id`, `color_partition`

**색상 배정**

- `color_variant`, `color_axis_side`
- `red_count`, `cyan_count`

**공간 하이퍼플레인**

- `spatial_plane_theta_rad`
- `spatial_plane_normal_x`, `spatial_plane_normal_y`
- `spatial_plane_offset`
- `spatial_plane_projection_gap`

**색상 하이퍼플레인**

- `color_plane_theta_rad`
- `color_plane_normal_x`, `color_plane_normal_y`
- `color_plane_offset`
- `color_plane_projection_gap`

**집합별 무게중심**

- `centroid_a_x`, `centroid_a_y`
- `centroid_b_x`, `centroid_b_y`

**자극 생성 및 공간 특성**

- `stimulus_generation_attempts`
- `n_mixed_spatial_groups`
- `min_pair_distance_actual`
- `overlapping_pair_count`
- `hull_area`
- `mean_nn_all`
- `within_cluster_mean_nn`
- `cross_cluster_min_distance`
- `spatial_ratio_actual`
- `max_center_distance`

**응답 데이터**

- `estimate`, `responded`, `timed_out`
- `correct`, `signed_error`, `absolute_error`
- `rt`, `chunks`, `n_chunks`
- `chunk_times`, `first_chunk_rt`
- `undo_count`, `partial_response`, `partial_chunks`
- `response_raw`, `response_status`

**화면 및 자극 설정**

- `canvas_logical_width`, `canvas_logical_height`
- `canvas_displayed_width`, `canvas_displayed_height`
- `dot_radius`, `minimum_dot_distance`
- `response_deadline_ms`, `time_elapsed`

`minimum_dot_distance`는 최초 점 배치에 적용된 제한값인 40px를 기록합니다.

`min_pair_distance_actual`은 무게중심 이동이 완료된 실제 점 사이 최소 중심거리입니다.

`overlapping_pair_count`는 이동 후 점 중심 간 거리가 14px 미만인 점 쌍의 개수를 의미합니다.

### 10.2. 점별 데이터

각 점에 대해 다음 정보를 기록합니다.

- `dot_index`: 시행 내 점의 번호
- `x`, `y`: 이동 후 점 좌표
- `initial_x`, `initial_y`: 이동 전 점 좌표
- `cluster`: 공간 집합 번호
- `color`: 점의 색상
- `phase`, `block`, `trial_in_block`, `main_trial_number`, `condition`: 해당 점이 속한 시행 정보

점 좌표는 소수점 첫째 자리까지 반올림하여 저장합니다.

### 10.3. 참가자 및 세션 데이터

세션별로 다음 정보를 기록합니다.

- `participant_id`
- `session_id`
- `experiment_version`
- `started_at_iso`, `finished_at_iso`
- 화면 크기 및 브라우저 정보
- 본 시행 수와 연습 시행 수
- 응답 수, 시간 초과 수, 정확도
- 초기 최소 점 중심거리 설정
- 자극 생성 방식 및 S 수준 정보

참가자 ID와 세션 ID는 세션 메타데이터에 포함됩니다. 현재 Google Apps Script로 전송하는 시행별·점별 행에는 이 두 ID를 별도 열로 추가하지 않습니다.

### 10.4. Google Apps Script 전송

실험 종료 후 참가자가 스페이스바를 누르면 데이터 전송을 시작합니다.

전송 방식은 다음과 같습니다.

1. 시행 데이터와 점 좌표를 수집합니다.
2. Google Apps Script 웹 앱에 JSON 형식으로 POST 요청을 보냅니다.
3. 서버가 `status: "ok"`를 반환하면 저장 성공 메시지를 표시합니다.
4. 전송 오류가 발생하면 최대 3회 재시도합니다.
5. 최종 전송 실패 시 CSV와 전체 JSON 데이터를 브라우저에 다운로드합니다.

현재 데이터 전송은 실험 종료 시 한 번 수행합니다. 진행 도중 브라우저를 종료하면 해당 세션의 데이터가 서버에 저장되지 않을 수 있습니다.

## 11. 구현 및 파일럿 확인 사항

### 11.1. 시행 구성

전체 본 시행이 315회로 생성되는지 확인합니다.

각 `(S, 점 개수, 색상 조건)` 조합은 정확히 한 번 등장해야 합니다.

### 11.2. 공간 분할

모든 점 개수에서 S=0%가 A로 시작하고 S가 3% 증가할 때마다 A/B가 교대하는지 확인합니다.

공간 집합별 점 개수가 목표 분할과 일치하는지 검증합니다.

### 11.3. 초기 점 최소거리

모든 초기 점의 중심 간 거리가 40px 이상인지 확인합니다.

점 개수 12개인 조건에서도 정상적으로 배치되는지 확인합니다.

거리 조건을 만족하지 않는 후보 점은 다시 추출합니다.

### 11.4. 무게중심 이동

S값에 따라 각 점이 자신의 공간 집합 무게중심을 향해 정확한 비율만큼 이동하는지 검증합니다.

같은 공간 집합의 점 사이 거리는 `(1-S)`배가 되어야 합니다.

### 11.5. 점 중첩

최초 점 생성에서는 40px 최소거리 조건이 적용되지만 무게중심 이동 후에는 별도의 거리 제한이 없습니다.

따라서 최종 점 중첩 여부와 실제 최소 점 중심거리를 확인합니다.

특히 S가 높은 조건에서 점 간 거리 분포가 어떻게 변화하는지 검토합니다.

### 11.6. C3 직교 분할

C3의 색상 분할선과 공간 분할선이 90° 관계인지 검증합니다.

공간 A에는 색상 B, 공간 B에는 색상 A의 목표 개수 조합이 적용되는지 확인합니다.

두 공간 집합 모두 빨강과 청록을 포함하는지 확인합니다.

### 11.7. 자극 재생성 및 분포

C3 조건에서는 두 공간 집합의 색상 혼합 요건을 만족하지 않는 자극을 다시 생성합니다.

`stimulus_generation_attempts`를 이용하여 S값과 점 개수에 따른 재생성 빈도를 검토합니다.

초기 최소거리 제한과 C3 재생성 조건이 최종 자극의 공간 분포에 미치는 영향도 검토합니다.

### 11.8. 데이터 전송

Google Apps Script를 통한 데이터 전송과 실제 저장 결과를 확인합니다.

시행별 데이터, 점별 데이터, 세션 정보가 올바르게 기록되는지 검사합니다.

연습과 본 시행을 합쳐 319개의 시행 데이터가 생성되는지 검증합니다.

Google Apps Script의 접근 권한, 데이터 기록 형식 및 중복 저장 방지 설정은 실제 참가자 모집 전에 확인해야 합니다.

## 12. 실행 방법

GitHub Pages 저장소에 `index.html` 파일을 배치하면 웹 브라우저에서 실험을 실행할 수 있습니다.

실험은 jsPsych 8.3.0과 관련 플러그인을 외부 CDN에서 불러옵니다.

참가자는 웹페이지에서 안내 및 연습 시행을 완료한 뒤 7개 블록, 총 315회의 본 시행을 수행합니다.

공간 하이퍼플레인, 색상 하이퍼플레인 및 무게중심은 내부 계산에만 사용되며 화면에는 점 자극만 표시됩니다.

실험 종료 후 데이터는 설정된 Google Apps Script 웹 앱으로 전송됩니다.
