# Groupitizing Experiment

공간적 그룹핑과 색상 그룹핑이 점 개수 판단에 미치는 영향을 조사하기 위한 웹 기반 시지각 심리학 실험입니다.

HTML과 JavaScript(jsPsych 8.3.0)로 구현되었으며, GitHub Pages를 통해 온라인으로 실행할 수 있습니다.

**현재 버전: 2.1.0**

## 1. 연구 목적

본 실험은 점 배열에서 공간적 그룹핑과 색상 그룹핑의 관계가 개수 판단에 미치는 영향을 조사합니다.

특히 공간적 클러스터가 형성되어 있을 때 색상 그룹핑이 공간 그룹핑과 일치하거나 불일치하는 경우, 그리고 색상이 무작위로 혼합된 경우의 차이를 비교합니다.

주요 측정 지표는 다음과 같습니다.

- 개수 판단 정확도(Accuracy)
- 반응시간(RT)
- 참가자가 보고한 그룹별 점 개수
- 참가자가 보고한 그룹 수(Reported chunks)

### 점 및 색상 설정

- 점 반지름: 7px
- 점 중심 간 최소 거리: 25px
- 배경: 흰색
- 회색: RGB(128, 128, 128)
- 빨강: RGB(255, 0, 0)
- 청록: RGB(0, 255, 255)

참가자별 HFP, DKL, 휘도 보정은 수행하지 않습니다. 고정된 RGB 색상을 사용합니다.

## 3. 실험 조건

전체 7가지 조건으로 구성됩니다.

| 조건 | 공간 배치 | 색상 배정 |
|---|---|---|
| R1 | 전체 무작위 | 무채색 |
| R2 | 전체 무작위 | 좌우 색 분리 |
| R3 | 전체 무작위 | 색상 무작위 혼합 |
| C1 | 2개 클러스터 | 무채색 |
| C2 | 2개 클러스터 | 공간·색상 분할 일치 |
| C3 | 2개 클러스터 | 공간·색상 분할 불일치 |
| C4 | 2개 클러스터 | 양쪽 클러스터 내부 색상 혼합 |

### R1~R3: 공간 무작위 조건

960×540px의 전체 자극 영역에서 모든 점의 좌표를 무작위로 생성합니다.

좌우 클러스터 중심이나 격자 구조를 사용하지 않으며, 점 사이 최소 거리만 제한합니다.

R2에서는 생성된 점을 x좌표순으로 정렬하여 지정된 개수만큼 왼쪽 색 그룹과 오른쪽 색 그룹에 배정합니다. 이 과정에서 점 좌표는 변경하지 않습니다.

R3에서는 빨강·청록의 전체 개수를 유지하면서 색상 라벨을 무작위로 배정합니다. 색이 완전히 좌우로 분리되는 경우는 제외합니다.

### C1~C4: 공간 클러스터 조건

화면을 좌우 두 영역으로 나누고 각 영역에 하나의 클러스터를 생성합니다.

클러스터 내부 점들의 위치와 클러스터 중심 위치는 시행마다 무작위로 생성됩니다.

클러스터 조건에서는 공간 분할 A/B를 이용해 두 클러스터에 들어갈 점 개수를 결정합니다.

## 4. 클러스터 중심 생성 알고리즘

### 4.1. 좌우 2×2 격자

자극 영역을 좌우로 나눈 뒤, 각 반쪽을 다시 2행 × 2열의 격자로 나눕니다.

- 왼쪽 영역: 4개 격자
- 오른쪽 영역: 4개 격자
- 각 격자의 크기: 240 × 270px

왼쪽과 오른쪽에서 각각 하나의 격자를 독립적으로 무작위 선택합니다.

격자별 등장 횟수는 균형화하지 않습니다. 각 시행에서 4개 격자가 동일한 선택 확률을 갖습니다.

선택된 격자는 자극 생성 과정에서 고정되며, 배치 조건을 만족하지 못할 경우 해당 격자 안에서 중심 좌표와 클러스터 크기를 다시 생성합니다.

격자선 및 클러스터 중심은 실제 실험 화면에 표시하지 않습니다.

### 4.2. 클러스터 크기

클러스터 반지름은 기본적으로 다음 범위에서 무작위 추출합니다.

- 최소 반지름: 65px
- 최대 반지름: 135px

기존 48~78px보다 큰 클러스터를 생성할 수 있도록 범위를 확장했습니다.

단, 실제 반지름은 클러스터 중심 위치 및 화면 경계에 따라 제한됩니다.

다음 조건을 만족해야 합니다.

1. 모든 점이 화면 안에 위치해야 합니다.
2. 점이 배정된 좌우 반쪽 영역을 벗어나지 않아야 합니다.
3. 두 클러스터의 원형 배치 범위가 지나치게 겹치지 않아야 합니다.
4. 점 사이 최소 거리 25px을 유지해야 합니다.
5. 클러스터의 원형 배치 범위 사이에 최소 38px의 간격을 확보해야 합니다.

클러스터 전체가 선택된 격자 안에 들어갈 필요는 없습니다. 격자는 클러스터 중심의 위치를 선정하는 용도로만 사용됩니다.

### 4.3. 내부 점 배치

각 클러스터의 원형 배치 영역 내부에 점을 무작위로 생성합니다.

반지름 방향의 위치는 원형 영역의 면적에 대해 균일하게 추출하며, 점 사이 최소 거리를 만족하지 않는 후보 좌표는 다시 생성합니다.

따라서 동일한 그룹 크기에서도 매 시행마다 서로 다른 점 배열이 만들어집니다.

## 5. 점 개수와 그룹 분할

전체 점 개수는 8~12개입니다.

각 전체 점 개수마다 두 종류의 그룹 분할을 사용합니다.

| 전체 점 개수 | 분할 A | 분할 B |
|---|---|---|
| 8 | 3+5 | 4+4 |
| 9 | 3+6 | 4+5 |
| 10 | 4+6 | 5+5 |
| 11 | 4+7 | 5+6 |
| 12 | 5+7 | 6+6 |

공간 분할 A/B와 색상 분할 A/B를 조합하여 일치·불일치 조건을 구성합니다.

## 6. 색상 배정 알고리즘

### C1: 무채색

모든 점을 회색으로 표시합니다.

### C2: 공간·색상 분할 일치

하나의 공간 클러스터에 하나의 색상을 배정합니다.

예를 들어 공간 분할이 4+4이면 색상 역시 4+4로 배정하고, 각 클러스터에 속한 점들은 같은 색을 갖습니다.

### C3: 공간·색상 분할 불일치

공간 분할 A에는 색상 분할 B를, 공간 분할 B에는 색상 분할 A를 적용합니다.

예를 들어 다음과 같습니다.

- 공간 분할: 4+4
- 색상 분할: 3+5

기본적으로 각 공간 클러스터에 서로 다른 색을 배정한 뒤, 전체 색상별 점 개수가 목표 분할을 만족하도록 **한 점의 색상을 변경**합니다.

#### C3의 다른 색 점 선택 규칙 (v2.1.0 변경)

기존에는 색상을 변경할 점 하나를 무작위로 선택했습니다.

현재 버전에서는 해당 클러스터의 점들 가운데 **반대편 클러스터 중심에 가장 가까운 점**을 선택합니다.

각 점의 x, y 좌표와 반대편 클러스터 중심 좌표를 이용하여 유클리드 거리를 계산합니다.

거리:

d = √((x_point − x_opposite_center)² + (y_point − y_opposite_center)²)

이 값이 가장 작은 점 하나의 색상을 변경합니다.

따라서 다른 색이 되는 점이 상대 클러스터를 향한 방향에 가깝게 위치하도록 구성됩니다.

이 과정에서도 점 좌표 자체는 변경하지 않습니다.

### C4: 양쪽 클러스터 내부 색상 혼합

두 공간 클러스터 각각에 빨강과 청록이 모두 포함되도록 색을 무작위 배정합니다.

전체 색상별 점 개수는 사전에 지정한 분할을 따릅니다.

C3와 달리 두 클러스터 모두 내부에 두 색이 섞여 있어야 합니다.

### 색상별 개수 균형화

동일한 색상 분할에 대해 빨강과 청록의 개수를 절반씩 반전합니다.

예를 들어 색상 분할 3+5가 12회 등장하면 다음처럼 구성합니다.

- 빨강 3 + 청록 5: 6회
- 빨강 5 + 청록 3: 6회

이 균형은 조건과 색상 분할별 시행 목록을 생성할 때 적용합니다.

|---|---|

| C1 | 60 |
| C2 | 60 |

각 블록에는 70회가 포함됩니다.

매 블록에서 각 점 개수와 실험 조건의 조합이 2회씩 등장하도록 구성합니다.

블록 내 시행 순서는 무작위화하며, 블록 사이에 참가자 휴식 화면을 제공합니다.

## 8. 참가자 응답 방식

### 8.1. 실험 시작

참가자는 시작 화면에서 이름을 입력합니다.

이후 실험 안내를 읽고 스페이스바를 누르면 연습 시행을 시작합니다.

### 8.2. 연습 시행

연습 시행은 총 4회입니다.

연습에서도 실제 본 실험과 동일한 자극 생성 및 응답 규칙을 사용합니다.

연습 응답 이후에는 참가자의 응답과 실제 정답을 표시합니다.

### 8.3. 본 시행

한 시행은 다음 순서로 진행됩니다.

1. 화면 중앙에 응시점 `+`를 1초 동안 표시합니다.
2. 점 배열과 입력 영역이 나타납니다.
3. 참가자는 지각한 그룹별 점 개수를 숫자 키로 입력합니다.
4. Enter를 누르면 그룹별 입력값을 자동 합산합니다.
5. 응답을 기록하고 다음 시행으로 진행합니다.

예를 들어 참가자가 3개, 4개, 3개의 그룹으로 지각했다면:

입력: `3` → `4` → `3` → `Enter`

자동 합산: 3 + 4 + 3 = 10

숫자 키 한 번이 그룹 하나에 해당합니다.

Backspace를 누르면 가장 최근에 입력한 그룹 개수를 취소합니다.

### 8.4. 응답 제한시간

최대 응답시간은 4초입니다.

**4초 이전에 Enter를 누르면 기다리지 않고 즉시 다음 시행으로 넘어갑니다.**

4초가 지나도록 Enter를 누르지 않으면 시간 초과로 처리합니다.

숫자를 일부 입력했더라도 Enter를 누르지 않았다면 미완료 응답으로 기록합니다.

본 시행에서는 정답 피드백을 제공하지 않습니다.

## 9. 데이터 기록

### 행동 데이터

- 실제 전체 점 개수
- 참가자가 입력한 그룹별 개수
- 입력 숫자의 합계
- 보고된 그룹 수
- 개수 판단 정확도
- Enter까지의 반응시간
- 첫 숫자 입력까지의 시간
- 각 숫자 입력 시점
- Backspace 사용 횟수
- 응답 완료 및 시간 초과 여부
- 시간 초과 시 미완료 입력 정보

반응시간은 점 제시부터 Enter 입력까지 측정합니다.

따라서 RT에는 개수 판단 과정뿐 아니라 숫자 키 입력에 걸린 시간도 포함됩니다.

### 자극 데이터

- 전체 점 개수 및 실험 조건
- 공간 그룹 분할
- 색상 그룹 분할
- 각 점의 실제 좌표
- 각 점의 색상 및 공간 클러스터 소속
- 클러스터 중심 좌표
- 선택된 2×2 격자 번호
- 클러스터 반지름
- 클러스터 중심 간 거리
- 클러스터 간 최소 거리
- 평균 최근접 거리
- 공간 거리 비율
- Convex hull 면적

C3의 색상 변경 결과도 각 점의 색상과 클러스터 소속을 통해 확인할 수 있습니다.

## 10. 데이터 전송 및 저장

실험 종료 후 Google Apps Script 웹 앱으로 데이터를 전송합니다.

기존 저장 구조를 유지하며 다음 데이터를 전송합니다.

- Trials: 시행별 조건 및 행동 결과
- Dots: 개별 점의 좌표, 색상, 클러스터 정보
- Session: 참가자 및 세션 메타데이터

데이터 전송은 최대 3회 재시도합니다.

전송이 실패하면 브라우저에서 CSV 및 JSON 백업 파일을 저장하도록 구성되어 있습니다.

실제 Google Sheets 저장 성공 여부는 연결된 Apps Script의 권한과 서버 처리 방식에 따라 달라질 수 있으므로 본격적인 자료 수집 전에 확인해야 합니다.

## 12. 연구 및 운영 시 주의사항
