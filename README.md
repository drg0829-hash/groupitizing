# Groupitizing Experiment

**Version 2.0.0 | Web-based Visual Numerosity Judgment Experiment**

> **설계 변경 사항:** C4 조건 제외, 총 6조건, 조건×점 개수별 16회 반복, 본 시행 480회(8블록 × 60회). 이 README는 변경 설계 사양이며, 실제 HTML/JavaScript 코드의 반영 여부는 별도로 확인해야 합니다.

공간적 그룹핑(Spatial Grouping)과 색상 그룹핑(Color Grouping)이 시각적 개수 판단에 미치는 영향을 조사하는 웹 기반 심리학 실험입니다.

HTML, JavaScript 및 jsPsych 8.3.0으로 구현되었으며, GitHub Pages를 통해 온라인으로 실행할 수 있습니다.

## 1. 연구 목적

본 실험은 점 배열에서 공간적 그룹핑과 색상 그룹핑의 관계가 개수 판단에 어떤 영향을 미치는지 조사합니다.

특히 공간적 그룹핑과 색상 그룹핑 단서가 일치하거나 불일치하는 경우를 비교하고, 전체 무작위 점 배열에서 색상 정보가 분리되거나 혼합되는 경우도 함께 조사하여 두 그룹핑 단서의 관계를 탐색합니다.

**주요 종속변수**

- **Accuracy:** 전체 점 개수 판단의 정확도
- **Reaction Time (RT):** 자극 제시부터 응답 완료까지의 시간
- **Reported Chunks:** 참가자가 보고한 그룹 수
- **Chunk Sizes:** 참가자가 보고한 각 그룹의 점 개수

참가자가 보고한 그룹 수는 지각적 그룹 분할을 간접적으로 반영하는 지표이며, 실제 인지적 청킹 횟수를 직접 측정한 값은 아닙니다.

## 3. 실험 조건

공간 배치와 색상 배정을 조합하여 총 6가지 조건을 구성합니다.

| 조건 | 공간 배치 | 색상 배정 |
|---|---|---|
| R1 | 전체 무작위 | 무채색 |
| R2 | 전체 무작위 | 좌우 색상 분리 |
| R3 | 전체 무작위 | 색상 무작위 혼합 |
| C1 | 2개 공간 클러스터 | 무채색 |
| C2 | 2개 공간 클러스터 | 공간·색상 그룹 일치 |
| C3 | 2개 공간 클러스터 | 공간·색상 분할 불일치 |

### 3.1. 전체 무작위 배치 조건(R1~R3)

점 좌표를 960 × 540px 자극 영역 전체에서 무작위로 생성합니다.

공간 클러스터를 별도로 지정하지 않으며, 점 중심 간 최소 거리 25px을 유지합니다.

- **R1:** 모든 점을 회색으로 표시합니다.
- **R2:** 점들을 x좌표순으로 정렬하여 지정된 개수만큼 빨강과 청록을 좌우로 분리합니다.
- **R3:** 색상별 점 개수를 유지하면서 빨강과 청록을 무작위로 배정합니다.

R2의 색상 경계는 실제 점들의 x좌표 분포에 따라 결정되므로 반드시 화면의 중앙선과 일치하지는 않습니다.

R3에서는 x좌표순으로 정렬했을 때 두 색상이 완전히 분리되는 배열을 제외합니다.

### 3.2. 공간 클러스터 조건(C1~C3)

화면을 왼쪽과 오른쪽 영역으로 나누고, 각 영역에 하나의 공간 클러스터를 생성합니다.

클러스터마다 중심 좌표, 반지름, 내부 점 좌표를 무작위로 결정합니다.

공간적 그룹의 점 개수는 사전에 정의한 그룹 분할에 따라 결정됩니다.

## 4. 공간 클러스터 생성 알고리즘

### 4.1. 클러스터 중심 선택

전체 자극 영역(960 × 540px)을 좌우로 분할합니다.

각 반쪽 영역(480 × 540px)을 다시 **2행 × 2열의 격자**로 나눕니다.

- 왼쪽 중심 후보 격자: 4개
- 오른쪽 중심 후보 격자: 4개
- 격자 하나의 크기: 240 × 270px

각 시행에서 왼쪽과 오른쪽의 격자를 독립적으로 무작위 선택합니다.

선택된 격자 내부에서 클러스터 중심 좌표를 추출하며, 배치 제약을 만족하지 않으면 해당 격자 안에서 다시 중심 좌표를 생성합니다.

격자는 클러스터 중심을 선택하기 위한 영역으로만 사용합니다. 클러스터의 원형 배치 범위가 한 격자 안에 모두 포함될 필요는 없습니다.

격자별 등장 횟수는 균등화하지 않으며, 격자선과 클러스터 경계는 참가자 화면에 표시되지 않습니다.

### 4.2. 클러스터 크기와 점 배치

각 클러스터의 기본 반지름 범위는 **65~135px**입니다.

실제 반지름은 중심 좌표와 화면 경계에 따라 허용 가능한 범위 안에서 무작위로 결정됩니다.

다음 조건을 만족하도록 점을 배치합니다.

1. 모든 점이 자극 영역 안에 위치해야 합니다.
2. 각 클러스터는 지정된 좌우 반쪽 영역을 벗어나지 않아야 합니다.
3. 점 중심 간 거리는 최소 25px을 유지해야 합니다.
4. 두 클러스터의 원형 배치 영역은 서로 겹치지 않아야 합니다.
5. 클러스터의 원형 배치 범위는 화면 중앙선으로부터 최소 35px 떨어져야 합니다.

따라서 좌우 클러스터의 원형 배치 범위 사이에는 최소 70px의 간격이 확보됩니다.

클러스터 내부에서는 원형 영역의 면적에 대해 균일하게 점 좌표를 추출하며, 최소 거리 조건을 위반하는 좌표는 제외합니다.

## 5. 점 개수 및 그룹 분할

전체 점 개수는 8~12개이며, 각 개수마다 두 가지 그룹 분할을 사용합니다.

| 전체 점 개수 | 분할 A | 분할 B |
|---|---|---|
| 8 | 3+5 | 4+4 |
| 9 | 3+6 | 4+5 |
| 10 | 4+6 | 5+5 |
| 11 | 4+7 | 5+6 |
| 12 | 5+7 | 6+6 |

공간 클러스터 조건에서는 이 분할에 따라 두 클러스터의 점 개수를 결정합니다.

색상 조건에서는 동일한 분할을 이용하여 빨강과 청록의 전체 점 개수를 결정합니다.

### 5.1. C2 — 공간·색상 일치

각 공간 클러스터의 모든 점에 하나의 색상을 배정합니다.

공간 분할과 색상 분할이 동일하며, 각 클러스터 내부에는 한 가지 색상만 존재합니다.

### 5.2. C3 — 공간·색상 불일치

공간 분할 A와 색상 분할 B, 또는 공간 분할 B와 색상 분할 A를 결합합니다.

예를 들어 전체 점 개수가 8개일 때 다음과 같은 조합을 사용합니다.

- 공간 분할: 4+4
- 색상 분할: 3+5

먼저 두 공간 클러스터에 서로 다른 색상을 배정한 다음, 색상별 점 개수가 목표 분할을 만족하도록 점 하나의 색상을 변경합니다.

**색상을 변경할 점의 선택 기준은 반대편 클러스터 중심까지의 유클리드 거리입니다.**

색상을 변경할 클러스터에 속한 점 중 반대편 클러스터 중심에 가장 가까운 점을 선택합니다.

\[
i^* = \arg\min_{i \in C} \|P_i-C_{\mathrm{opposite}}\|
\]

이 규칙을 통해 다른 색을 갖는 점 하나가 상대 클러스터를 향한 방향에 위치하도록 구성합니다.

색상만 변경하며 점의 좌표는 유지합니다.

## 6. 실험 조건의 균형화

### 6.1. 시행 수와 블록 구성

본 시행은 다음과 같이 구성됩니다.

**5개 점 개수(8~12개) × 6개 조건(R1~R3, C1~C3) × 16회 반복 = 480회**

- 각 **조건 × 점 개수 조합**: 16회
- 각 **조건 전체**: 5개 점 개수 × 16회 = 80회
- 각 **점 개수 전체**: 6개 조건 × 16회 = 96회
- **본 시행**: 480회
- **연습 시행**: 4회(별도)
- **연습 포함 총 시행**: 484회

본 시행은 **8개 블록 × 60회**로 구성합니다.

매 블록에 **6개 조건 × 5개 점 개수 × 2회 = 60회**를 배정합니다. 각 조건 × 점 개수 조합의 2회는 해당 조건에서 A/B 분할이 적용되는 경우 **분할 A와 분할 B를 각 1회씩** 배정합니다. C3에서는 **공간 A·색상 B**와 **공간 B·색상 A**를 각 1회씩 배정합니다. R1에는 분할 A/B를 적용하지 않습니다.

블록 내부 시행 순서는 무작위화합니다. 8개 블록을 모두 합치면 각 조건 × 점 개수 조합이 16회 등장합니다.

### 6.2. 공간 및 색상 분할 균형

각 조건 × 점 개수 조합에서 A/B 분할이 적용되는 경우, **16회 중 분할 A 8회와 분할 B 8회**로 구성합니다.

- **R1:** 공간·색상 분할을 적용하지 않습니다.
- **R2·R3:** 색상 분할 A/B를 각각 8회 사용합니다.
- **C1·C2:** 공간 분할 A/B를 각각 8회 사용합니다. C2에서는 공간 분할과 색상 분할이 일치합니다.
- **C3:** 공간 분할 A·색상 분할 B를 8회, 공간 분할 B·색상 분할 A를 8회 사용합니다.

색상 분할 내에서는 빨강과 청록의 점 개수를 가능한 범위에서 반전시켜 균형화합니다. **서로 다른 개수로 나뉘는 분할**에서는 해당 분할의 8회 중 두 색상의 개수 반전을 **4:4**로 배정합니다.

예를 들어 색상 분할이 3+5로 지정된 8회 중:

- 빨강 3개 + 청록 5개: 4회
- 빨강 5개 + 청록 3개: 4회

4+4, 5+5, 6+6과 같은 **동수 분할**은 점 개수를 반전해도 구성이 달라지지 않으므로, 빨강·청록의 좌우 배정이나 공간 클러스터 배정을 통해 방향 균형을 맞춥니다.

### 6.3. 좌우 방향 균형

**R2**에서는 각 색상 분할의 8회 중 빨강이 왼쪽에 배정되는 시행과 오른쪽에 배정되는 시행을 **4:4**로 구성합니다. 서로 다른 색상 개수의 분할에서는 빨강·청록 개수 반전(4:4)과 좌우 방향(4:4)을 함께 균형화합니다.

**C1~C3**에서는 공간 분할 A/B 각각 8회 안에서, 양쪽 공간 클러스터의 점 개수 배정 방향을 가능한 범위에서 균형화합니다. 서로 다른 점 개수로 나뉘는 공간 분할은 큰 그룹 또는 작은 그룹이 왼쪽과 오른쪽에 각각 4회씩 나타나도록 합니다. 동수 분할은 크기만으로 좌우 방향을 구분할 수 없습니다.

**C2·C3**에서는 각 조건 × 점 개수 조합의 16회 중 빨강이 우세한 공간 클러스터가 왼쪽과 오른쪽에 각각 **8회씩** 나타나도록 구성합니다. 분할별 8회에서도 빨강 우세 방향을 **왼쪽 4회 : 오른쪽 4회**로 균형화합니다.

공간 분할의 좌우 배정, 빨강 우세 방향, 색상 점 개수의 반전은 해당 조건에서 가능한 조합 안에서 함께 조정합니다. 특히 C3는 **두 분할의 불일치를 점 하나의 색상 변경으로 만드는 규칙**을 계속 지켜야 하므로, 불가능한 요인 조합을 강제로 만들지 않습니다.

**R3**는 전체 무작위 점 배열에서 색상이 혼합되는 조건이므로 빨강의 좌우 우세 방향에 대해 별도의 균형화 제약을 적용하지 않습니다.

## 7. 실험 진행 절차

### 7.1. 참가자 정보 및 안내

실험 시작 시 참가자 이름을 입력합니다.

이후 실험 안내 화면에서 과제 수행 방법과 응답 규칙을 확인합니다.

### 7.2. 연습 시행

본 실험 전에 총 4회의 연습 시행을 진행합니다.

연습에서는 참가자의 응답과 실제 정답을 1초 동안 보여줍니다.

### 7.3. 본 시행

각 시행은 다음 순서로 진행됩니다.

1. 응시점 `+` 제시 — 1,000ms
2. 점 배열 제시 및 키보드 응답 — 최대 4,000ms
3. 빈 화면(ITI) — 300ms
4. 다음 시행 진행

블록 사이에는 참가자가 원하는 만큼 휴식한 뒤 스페이스바를 눌러 다음 블록을 시작할 수 있습니다.

### 7.4. 응답 방법

참가자는 지각한 그룹별 점 개수를 숫자 키로 차례로 입력합니다.

예를 들어 점들을 3개, 4개, 3개로 지각했다면:

`3` → `4` → `3` → `Enter`

입력 중 화면에는 다음과 같이 표시됩니다.

`3 + 4 + 3`

**입력 중 합계는 표시하지 않습니다.**

프로그램은 내부적으로 합계를 계산하여 전체 점 개수에 대한 최종 응답으로 기록합니다.

- `1~9`: 그룹별 개수 입력
- `Backspace`: 마지막 입력 취소
- `Enter`: 응답 제출

숫자 키 한 번의 입력은 하나의 그룹에 해당합니다.

### 7.5. 응답 제한시간

점 배열은 최대 4초 동안 표시됩니다.

- 4초 이내에 Enter를 누르면 즉시 시행이 종료됩니다.
- Enter를 누르지 않은 채 4초가 지나면 시간 초과로 처리합니다.
- 숫자만 입력한 상태에서 시간이 초과되면 미완료 응답으로 기록합니다.
- 응답 종료 후 300ms의 빈 화면을 거쳐 다음 시행으로 진행합니다.

본 실험에서는 정답 피드백을 제공하지 않습니다.

## 8. 자극 표시 및 화면 크기

자극 생성에는 960 × 540px의 논리 좌표계를 사용합니다.

실제 표시 크기는 브라우저의 화면 크기에 따라 조절됩니다
