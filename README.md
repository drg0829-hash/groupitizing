# Groupitizing Experiment

**Version 3.0.0 | Hyperplane-Based Web Numerosity Judgment Experiment**

> **설계 변경 요약:** 기존 R1~R3 및 원형 클러스터 생성 알고리즘을 제거하고, 무작위 점 배열 → 공간 하이퍼플레인 분할 → 무게중심 방향 이동(S)이라는 공통 알고리즘으로 통합했습니다. S는 0~60%를 3% 간격으로 조작하며, 색상 배정은 C1(무채색)·C2(공간과 일치)·C3(직교 분할)의 세 가지입니다. **본 시행 315회(7블록 × 45회)**, 연습 4회로 구성됩니다. 기존의 점 중심 간 최소거리 25px 제약은 제거했습니다.

본 실험은 공간적 그룹핑(Spatial Grouping)의 강도와 색상 그룹핑(Color Grouping)의 일치·불일치가 시각적 개수 판단에 미치는 영향을 조사합니다. HTML, JavaScript 및 jsPsych 8.3.0으로 구현하며 GitHub Pages에서 실행할 수 있습니다.

## 1. 연구 목적 및 종속변수

무작위로 생성한 점 배열을 두 집합으로 분할한 후 각 집합의 무게중심을 향해 점을 일정 비율만큼 이동시킵니다. **공간 군집화 강도 S(0~60%)**와 **색상 배정 방식(C1~C3)**을 조합하여 개수 판단의 변화를 살펴봅니다.

- **Accuracy:** 전체 점 개수 판단의 정확도
- **Reaction Time (RT):** 자극 제시부터 Enter 제출까지의 시간
- **Reported Chunks:** 참가자가 입력한 그룹별 숫자의 개수
- **Chunk Sizes:** 참가자가 입력한 각 그룹의 점 개수

Reported Chunks는 지각적 그룹 분할의 **간접 지표**이며 실제 인지적 청킹 횟수를 직접 측정한 값은 아닙니다.

## 3. 세 가지 색상 배정 조건

세 조건 모두 **동일한 원리의 공간 분할 및 S 이동**을 먼저 수행합니다.

| 조건 | 공간 생성 | 색상 배정 |
|---|---|---|
| **C1 — 무채색** | 공간 하이퍼플레인 → S만큼 이동 | 모든 점 회색 |
| **C2 — 일치(Congruent)** | C1과 동일 | 공간 하이퍼플레인 양쪽 집합에 빨강·청록 각각 배정 |
| **C3 — 직교 불일치(Incongruent)** | C1과 동일 | 공간 분할선과 직교하는 새 색상 분할선을 이용해 빨강·청록 배정 |

S=0%에서는 이동이 없어 점의 **공간 좌표가 무작위 배치 상태 그대로** 유지됩니다. 따라서 C1의 S=0%는 과거 R1과 유사한 무채색 기준조건입니다. C2·C3의 S=0%도 같은 좌표 생성 규칙을 쓰지만 색상은 각 하이퍼플레인 기준으로 분리됩니다. **기존 R3처럼 색을 완전히 무작위로 혼합하는 독립 조건은 이번 버전에서 사용하지 않습니다.**

## 4. 공통 자극 생성 알고리즘

### 4.1. 초기 무작위 점 배치

1. 전체 점 개수 `n ∈ {8, 9, 10, 11, 12}`를 선택합니다.
2. 960×540px 화면에서 점 중심이 테두리 및 기본 여백을 벗어나지 않도록 각 점의 `(x, y)`를 **독립적으로 균등 무작위 추출**합니다.
3. **점 간 최소 중심거리 제한을 적용하지 않습니다.** 초기 점끼리 가까울 수도 있고, 이후 이동한 점들이 서로 겹칠 수도 있습니다.

기존의 좌우 반쪽 분리, 2×2 격자 및 65~135px 원형 클러스터 생성 방식은 사용하지 않습니다.

### 4.2. 공간 하이퍼플레인 선택

하이퍼플레인은 2차원 화면에서는 **분할 직선**입니다. 목표 공간 분할 A/B를 정한 후 다음 절차로 직선을 선택합니다.

1. 후보 각도 `θ`를 원 전체 방향에서 약 180개 생성합니다.
2. 각 각도의 단위 법선벡터 `u=(cos θ, sin θ)`를 구합니다.
3. 모든 점 `Pᵢ=(xᵢ,yᵢ)`의 투영값 `tᵢ=xᵢ cos θ + yᵢ sin θ`를 구해 정렬합니다.
4. 첫 번째 공간 집합의 목표 크기를 `k`라고 할 때, 정렬된 `k`번째와 `k+1`번째 투영값 사이의 간격을 계산합니다.
5. 이 **간격이 가장 큰 후보 방향**을 선택하고, 두 투영값의 중간을 분할선의 절편 `c`로 정합니다.

분할선의 식은 `u·P=c`입니다. 투영값이 작은 쪽은 집합 0, 큰 쪽은 집합 1로 구분되며 **목표 공간 분할 개수가 정확히 보장**됩니다.

이 선택 규칙은 두 집합 사이의 투영 간격을 넓히기 위한 것으로, 공간 그룹핑의 지각적 강도가 동일하다는 보장은 아닙니다.

### 4.3. 각 집합의 무게중심으로 이동

분할한 두 집합의 초기 점 좌표로 무게중심 `μ₀, μ₁`을 계산합니다. 각 점을 자신이 속한 집합의 무게중심 방향으로 다음과 같이 이동합니다.

`Pᵢ' = (1 − S) Pᵢ + S μ_group(i)`

- S=0%: 이동 없음 (초기 무작위 좌표 유지)
- S=30%: 자신의 집합 무게중심까지 남은 거리의 30% 이동
- S=60%: 자신의 집합 무게중심까지 남은 거리의 60% 이동

이동은 실제 점 좌표에 적용됩니다. 하이퍼플레인 양쪽에서 계산된 각 집합의 무게중심도 해당 반평면 안에 있으므로, 이 이동으로 점이 원래 공간 분할선을 넘어가지는 않습니다. 또한 화면 내 점들의 볼록 결합이므로 화면 경계도 벗어나지 않습니다.

**중요:** 최소거리 조건을 없앴으므로 두 점의 원이 겹쳐 보일 수 있습니다. 실험에서는 이를 자동 제거하지 않고, 실제 최소 점 중심거리 및 겹친 점 쌍의 개수를 기록합니다. 겹침이 개수 판단에 영향을 줄 수 있으므로 내부 파일럿에서 반드시 확인해야 합니다.

## 5. 점 개수와 공간 분할 A/B

| 총 점 개수 | 공간 분할 A | 공간 분할 B |
|---|---|---|
| 8 | 3+5 | 4+4 |
| 9 | 3+6 | 4+5 |
| 10 | 4+6 | 5+5 |
| 11 | 4+7 | 5+6 |
| 12 | 5+7 | 6+6 |

공간 분할은 별도 시행 수를 곱하는 독립 실험 요인이 아닙니다. **모든 점 개수에서 A부터 시작**하여 S값이 3% 증가할 때마다 A/B를 교대로 배정합니다.

- S=0% → A
- S=3% → B
- S=6% → A
- S=9% → B
- …
- S=57% → B
- S=60% → A

따라서 **각 점 개수 × 각 색상 조건의 21회** 안에서 A는 11회, B는 10회 사용합니다. 동일한 `(S, n)` 조합에서는 C1·C2·C3 모두 **같은 공간 분할 유형**을 사용하지만, 점 좌표와 하이퍼플레인은 시행마다 새로 생성합니다.

**A/B가 뜻하는 것은 두 집합의 점 개수 유형이지, 화면의 고정된 왼쪽/오른쪽 영역이 아닙니다.** 분할선의 방향은 매 시행 탐색하여 결정합니다.

## 6. 색상 배정 규칙

### 6.1. C1 — 무채색

S 이동까지 마친 모든 점을 회색으로 표시합니다. 공간 분할선이나 두 집합의 경계는 화면에 표시하지 않습니다.

### 6.2. C2 — 공간·색상 일치

공간 하이퍼플레인으로 만든 집합 0과 집합 1을 각각 단색으로 칠합니다. 한 집합은 빨강, 나머지는 청록입니다. 같은 집합 안에 두 색이 섞이지 않습니다. 빨강과 청록의 배정 방향은 S 단계와 점 개수에 따라 10:11 또는 11:10 수준으로 반전합니다.

### 6.3. C3 — 직교 색상 분할

공간 분할선을 결정하고 점을 S만큼 이동시킨 **후**, 공간 분할선에 직교하는 **새 색상 분할선**을 설정합니다.

1. 공간 분할선의 법선이 `u=(uₓ,uᵧ)`이면, 색상 분할선의 법선은 `v=(-uᵧ,uₓ)`로 정합니다.
2. 이동한 점들을 색상 법선 `v` 방향으로 투영해 정렬합니다.
3. 색상 분할선의 절편을 **목표 빨강·청록 개수**에 맞게 선택합니다. 분할선은 공간 하이퍼플레인과 90°로 교차하지만 반드시 같은 절편이나 화면 중심을 지날 필요는 없습니다.
4. 빨강이 투영값이 작은 쪽 또는 큰 쪽에 나타나도록 배정 방향을 교대시킵니다.
5. **각 공간 집합에 빨강과 청록이 모두 들어 있어야** 통과시킵니다. 한 공간 집합이 단색이라면 자극을 처음부터 다시 생성합니다.

이렇게 하면 이전 버전의 **'점 하나만 색 반전'** 방식 대신, 공간과 색상의 분할 기준이 실제로 교차하도록 구성합니다.

### 6.4. 기존 A/B 개수 교차 유지

C3의 공간 분할과 색상 분할의 **목표 점 개수**는 기존처럼 반대로 결합합니다.

- 공간 A → 색상 B
- 공간 B → 색상 A

예를 들어 `n=8`, 공간 A(3+5)라면 색상은 B(4+4)입니다. `n=10`, 공간 B(5+5)라면 색상은 A(4+6)입니다. 빨강·청록의 개수 방향도 가능한 한 균형 있게 바꿉니다.

**주의:** 분할쌍 교차는 색 개수에 대한 조건이며, 새 C3는 색이 바뀌는 점을 하나만 선택하지 않습니다. 색 분할 직선을 이용합니다.

## 7. 시행 수와 블록 구성

S 단계는 0%, 3%, 6%, …, 60%의 **21개**입니다. 각 S에서 3조건 × 점 개수 5종을 각각 한 번씩 시행합니다. 같은 `S × n × 색상 조건`의 반복은 1회이며, 공간 분할 A/B는 5절의 결정적 교대 규칙으로 배정하므로 추가로 2를 곱하지 않습니다.

**21개 S × 3개 색상 조건 × 5개 점 개수 = 본 시행 315회**

| 구분 | 시행 수 |
|---|---:|
| C1 (무채색) | 105회 |
| C2 (일치) | 105회 |
| C3 (직교 불일치) | 105회 |
| 점 개수별 합계(8, 9, 10, 11, 12 각각) | 63회 |
| S 단계별 합계(0~60% 각 단계) | 15회 |
| **본 시행 총합** | **315회** |
| 연습 | 4회 |
| **연습 포함 합계** | **319회** |

**블록:** 7개 블록 × 45회. 각 블록은 낮은 S 구간(0~18%), 중간 구간(21~39%), 높은 구간(42~60%)에서 **각 1개 S값**을 배정합니다. 각 S값에 5개 점 개수 × 3개 색상 조건 = 15회가 있으므로 블록당 45회가 됩니다. 각 블록에서 A 수준 1~2개와 B 수준 1~2개가 되도록 구성하고, 블록 안의 시행 순서는 무작위로 섞습니다.

전체 7개 블록을 합치면 모든 S 단계가 정확히 한 번씩 블록에 배정됩니다. 블록별 S값 배정 및 시행 순서는 실행할 때마다 무작위화되지만, 각 `(S, n)`의 A/B 유형은 항상 동일합니다.

## 8. 실험 진행 절차

### 8.1. 참가자 정보와 안내

시작 화면에서 참가자 이름을 입력합니다. 점의 색과 무관하게 **전체 점 개수**를 세도록 안내합니다.

### 8.2. 연습 시행

연습은 총 4회이며, 응답 후 **1초 동안 정답과 참가자 응답**을 보여 줍니다. 연습 자극도 새로운 공간 하이퍼플레인 생성 알고리즘을 사용합니다.

### 8.3. 본 시행

1. 응시점 `+` — 1,000ms
2. 점 배열 제시 및 키보드 응답 — 최대 4,000ms
3. 빈 화면 — 300ms
4. 다음 시행

참가자는 블록 사이에서 스페이스바를 눌러 다음 블록을 시작합니다. 본 시행에서는 정답 피드백을 제공하지 않습니다.

### 8.4. 응답 방법

보이는 그룹별 개수를 숫자 키 `1~9`로 차례로 입력합니다. 예를 들어 3개, 4개, 3개로 인식했다면 `3 → 4 → 3 → Enter`를 누릅니다. 화면에는 `3 + 4 + 3`처럼 입력한 숫자만 표시되며 **합계는 표시되지 않습니다**.

- `1~9`: 그룹별 개수 입력
- `Backspace`: 마지막 숫자 취소
- `Enter`: 각 숫자의 합계를 전체 점 개수 응답으로 제출하고 즉시 시행 종료
- 응답 제한시간 4초가 끝나면 미제출 상태로 종료하며 부분 입력은 별도로 기록

## 9. 화면 크기 및 표시

자극 생성에는 논리 좌표계 **960×540px**을 사용합니다. CSS에서 브라우저 크기에 맞게 비례 축소하며 좌표계의 비율은 유지합니다. 점의 반지름은 논리 좌표에서 7px입니다. 공간·색상 분할선, 투영축, 무게중심은 계산 용도이며 실제 자극에는 **점만 표시**합니다.

- 색상: `color_variant`, `color_axis_side`, `red_count`, `cyan_count`
- 공간 분할선: `spatial_plane_theta_rad`, `spatial_plane_normal_x`, `spatial_plane_normal_y`, `spatial_plane_offset`, `spatial_plane_projection_gap`
- 색상 분할선: `color_plane_theta_rad`, `color_plane_normal_x`, `color_plane_normal_y`, `color_plane_offset`
- 그룹 무게중심: `centroid_a_x`, `centroid_a_y`, `centroid_b_x`, `centroid_b_y`
- 자극 검증: `stimulus_generation_attempts`, `n_mixed_spatial_groups`, `min_pair_distance_actual`, `overlapping_pair_count`
- 반응: `estimate`, `correct`, `rt`, `chunks`, `chunk_times`, `undo_count`, `timed_out`, `partial_response`
- 점별 원자료: 이동 전 좌표(`initial_x`, `initial_y`), 이동 후 좌표(`x`, `y`), 공간 집합(`cluster`), 색상(`color`)

원형 클러스터의 격자 번호·반지름 등 기존 방식에만 필요한 데이터는 더 이상 생성하지 않습니다. 입력 데이터의 **절대 최소거리 제한은 0(제한 없음)**으로 기록합니다.

## 11. 구현 및 파일럿 확인 사항

1. **315회 정확 배정:** 각 S×점 개수×C1/C2/C3가 정확히 한 번 등장하는지 확인합니다.
2. **공간 A/B 교대:** 모든 점 개수에서 S=0%는 A, S=3%는 B로 시작하는지 확인합니다.
3. **C3 개수 교차:** 공간 A이면 색상 B, 공간 B이면 색상 A인지 확인합니다.
4. **직교 및 색상 혼합:** C3 색상 분할선이 공간 분할선과 90°를 이루고 두 공간 집합 모두 두 색을 포함하는지 확인합니다.
5. **점 중첩 영향:** 최소거리 제한 제거로 발생하는 점들의 시각적 중첩이 개수 판단에 영향을 주는지 검토합니다. 특히 높은 S에서 중첩이 늘어날 가능성이 있습니다.
6. **분할선 선택 편향:** 후보 각도 중 최대 투영 간격을 선택하므로 특정 공간 방향이 과도하게 선택되는지 점검합니다.
7. **외부 저장:** 기존 Google Apps Script 전송을 유지했지만, 서버 저장 형식과 공개 웹 페이지의 인증·접근 설정은 배포 전 확인이 필요합니다. HTML 안의 저장 인증 문자열은 공개 웹에서 비밀로 보호되지 않습니다.
